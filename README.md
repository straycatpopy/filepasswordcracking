# filepasswordcracking#
Password Cracking Using John the Ripper

Operating System: Kali Linux  
Tool Used:** John the Ripper (JTR)

 Description
This practical involved using John the Ripper to perform a dictionary attack on password hashes and identify weak passwords.

## Commands Used
john (my file location)


 Results
The password recovered during the exercise was:
nopassword
## Challenges
I initially attempted to use Johnny (GUI) but encountered difficulties. I switched to the command-line version of John the Ripper and successfully completed the practical.

 Conclusion
The exercise helped me understand dictionary attacks, password recovery, and the importance of using strong passwords.
